# Privacy policy

_Last updated: 24 September 2026_

KeyboardLayoutReset does not collect, store, send or share any personal
information.

- It has no network access and never connects to the internet.
- It contains no analytics, telemetry, advertising or crash reporting.
- It does not read or record what you type. It only asks Windows how long ago
  the last keyboard or mouse input happened, and which keyboard layout the
  active window uses.
- It stores two settings on your own computer, in the Windows registry under
  `HKEY_CURRENT_USER\Software\KeyboardLayoutReset`: the default keyboard and
  the idle time. Uninstalling the app removes them.

This applies to the Microsoft Store version and to the installer from GitHub.

Questions: open an issue at
<https://github.com/gasparovicm/KeyboardLayoutReset/issues>.
